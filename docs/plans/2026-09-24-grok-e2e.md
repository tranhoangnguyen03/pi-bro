## Access and retention

Grok advisor is intentionally workspace-full (`--sandbox off`, bypassPermissions), not sandboxed or read-only. The no-edit request is behavioral. Grok hooks, skills, plugins, MCP and other inherited configuration may load. Subagent/scheduler/monitor/workflow tools are explicitly disabled. Cancellation targets the managed process group, not independently detached shell work or external services. Bro removes its private temporary prompt file after execution; Grok can retain its own session/log data. Bro never copies credentials or rewrites Grok config.

Restricted features are not enabled merely because `--tools ''` or a scratch cwd is available: those controls do not disable inherited hooks/configuration. This release does not wire Grok continuation for BTW.

Verified locally: 94 tests plus offline smoke checks; live Grok 1.0.41 / grok-4.7-build-fast / low effort read a disposable workspace canary through the final adapter flags and returned the exact token. Other model/effort combinations and Windows were not live-tested.
